# 助盲跑 - 无障碍运动陪伴平台

## 项目简介
助盲跑是一款帮助视障人士与志愿者进行跑步匹配的 Android 应用。  
盲人可一键发起实时求助或预约陪跑，志愿者通过地理位置和配速匹配接单，并提供语音导航。  
平台还包含运动数据记录、信用评分、评价反馈等功能，旨在打造安全、高效的无障碍运动社区。

## MVP 功能清单（当前版本）
- 注册登录（盲人/志愿者身份分离）
- 实时匹配（盲人一键求助 + 志愿者接单 + 地理围栏算法）
- 预约跑步（盲人创建预约，志愿者确认/拒绝）

## 技术栈
- 语言：Kotlin / Java（推荐 Kotlin）
- 最低 SDK：API 24 (Android 7.0)
- 架构：MVVM + LiveData + Room（数据存储）
- 地图：高德地图或百度地图 SDK（用于定位与导航）

## 如何运行
1. 克隆本仓库  
2. 使用 Android Studio 打开项目  
3. 同步 Gradle 并下载依赖  
4. 连接真机或启动模拟器（需要 GPS 支持）  
5. 运行 app 模块
